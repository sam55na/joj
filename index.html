📡 API - sports-skills

المصدر: جميع البيانات تُجلب مباشرة من واجهة sports-skills API (مكتبة Python مفتوحة المصدر) ولكن تم تحويلها لـ REST endpoint عبر خدمة مجانية. يتم الحصول على المباريات، الترتيب، الهدافين، إحصائيات الفرق، وتاريخ المواجهات.
يتم جلب البيانات عبر API endpoint عام: https://sports-skills-api.vercel.app/api/...
• المباريات: /fixtures?league={league}
• الترتيب: /standings?league={league}
• الهدافون: /topscorers?league={league}
• إحصائيات المباراة و H2H عبر endpoints مخصصة.
